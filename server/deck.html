03 อ่านอะไรจาก Resolve ได้บ้าง

ใช้ scripting API อย่างเดียว — read-only (Get*) ทั้งหมด

อ่านจากได้ข้อมูลใช้ทำ
GetCurrentPageหน้าที่เปิดอยู่ (edit / color / fusion…)รู้ว่ากำลังทำ stage ไหน
GetStart/EndFrameความยาว timelineตัวตั้ง % ของ conform
GetItemListInTrackจำนวน clip บน timelineตัวหารของ color
GetNodeGraph · GetNumNodesclip ไหนถูกเกรดสีแล้ว% color = เกรดแล้ว/ทั้งหมด
GetMarkersรหัส shot + หมายเหตุบน markerไล่สถานะราย shot
IsRenderingInProgressกำลัง render อยู่ไหม (ปลอดภัย)รู้ว่าเข้าขั้น output

metric 02 (active/idle): API ของ OS — idle + แอปหน้าสุด (Linux/Mac) ไม่ใช่แคปหน้าจอ

05 ถ้าต้องการลึกสุด · ต่อ clip

เปิด flag เดียว ดึงได้ทุกอย่างที่ Resolve ยอมให้อ่าน · default ปิด

เปิดใช้งาน (ต่อเครื่อง)
export EDITORTRACK_EXTRACT_CLIP_META=1
export EDITORTRACK_CLIP_META_MAX=50   # จำกัดจำนวน clip (0 = ทั้งหมด)
⚠
ยืนยันด้วย probe.py ก่อนเปิดจริง — method ชั้นเกรดสี/version เปลี่ยนตาม Resolve version

08 สถานะตอนนี้

อะไรพิสูจน์แล้ว อะไรกำลังทำต่อ

✓ พิสูจน์แล้ว

  • ✓ อ่าน Resolve ได้จริง (ทดสอบบนโปรเจค 309 clip)
  • ✓ วัด active/idle ข้ามแพลตฟอร์ม (Mac / Win / Linux)
  • ✓ join งานจาก ERP booking (ห้อง+เวลา)
  • ✓ color = เกรดแล้ว/ทั้งหมด · conform = เทียบ offline

● กำลังทำต่อ

  • ● เปิดช่องให้ ERP รับค่า % กลับ (รอสเปก endpoint)
  • ● ยืนยันตัว 🟠 ของ clip-meta ลึกบนเครื่องจริง (probe §5d)
  • ● ตั้งเป้าของ subtitle / master เพื่อเปิด %
  • ● ติดตั้งลงครบ 7 เครื่อง (6 เกรด + 1 conform)
